# Grok Bot in this team

Atlas is the first Grok Bot specialist. Codex remains the coordinator: it gives
Atlas a bounded task, checks the answer, records what was useful, and decides the
next step. Atlas is available in the official Windows app installed under
`C:\Program Files\Grok Bot`. The first panel proposal task completed on September
7, 2026; Atlas also completed the shared discussion and its final ballot. The
service did not disclose an exact model identifier.

Open the app and select Atlas to continue. For additional specialists, use New
and create a Bot with one clear job. The current panel uses Atlas for visual
product review. Desktop Bots and Grok Build CLI workers are separate interfaces;
multiple Bots do not establish multiple underlying model families.

Before work, open your profile menu, Settings, then Usage & Billing. The app's
weekly allowance is separate from Grok Build. Codex records a dated reading in
the `grokbot-weekly` pool and reserves the expected task allowance. The default
warning is 20%, with 10% preserved plus room for the proposed task.

The current integration requires a fresh visible reading. It does not have an
automatic Bot quota reader or a verified external Bot-control API. Readings
expire after ten minutes, which holds new assignments and lets the monitor warn
about the unverified allowance. Never substitute Grok Build's percentage.

The observed setup screen showed 1% weekly use after onboarding, zero on-demand
spend, and an invitation to enable on-demand usage. Codex changed no billing or
account links. Inspect current settings again before relying on this old reading.

For supplied-text tasks, keep the app's existing review controls, provide only
the approved brief, prohibit unrelated actions, and inspect the returned result.
Prompt instructions are not an operating-system sandbox. No account connectors
are needed for the panel's generic idea, discussion and voting tasks.

All-users installation is this user's preference when officially supported. A
per-user install works for this Windows account too; reinstalling solely to
change scope is unnecessary.
